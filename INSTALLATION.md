# Installation and recovery

There is no validated UPA50 package available yet. Do not flash this source
branch or an unvalidated workflow artifact.

When a package is released, use only a ZIP whose edition, ROM variant, and
Android version match the device's installed ROM. Before flashing, use the
device's recovery to back up the stock boot image and keep that backup
available for recovery. Restore the saved stock boot image from recovery if
the device does not boot. Exact package and recovery steps will be documented
after a package has been built and validated; flashing has not been tested.
