# KernelSU-Next

The planned KernelSU-Next edition will use the official `v3.4.2` release at
commit `4c706b5938665866ebe16944a481a7b91e3396af`. The tag was confirmed to
resolve to that commit. No KernelSU-Next overlay has been integrated or built.

The Standard edition must contain no KernelSU, KernelSU-Next, or SuSFS code or
configuration. That purity requirement is not yet implemented or verified.
